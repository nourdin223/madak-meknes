# مذاق مكناس — V2
## جاهز كبداية للنشر على Vercel

### قبل النشر
- بدّل `YOUR-DOMAIN.vercel.app` بالدومين الحقيقي في canonical/hreflang/sitemap/JSON-LD.
- بدّل `212600000000` برقم WhatsApp الحقيقي.
- بدّل الصور التجريبية بصور المنتجات والمصدر الحقيقية.
- بدّل الأسعار والمعلومات الغذائية والقانونية حسب الواقع.
- أضف رابط Instagram وGoogle Maps الحقيقيين.
- أضف صفحات المنتجات والمقالات الحقيقية.

### النشر
ارفع المجلد إلى GitHub ثم اختر Import Project في Vercel.

### ملاحظة
SEO لا يضمن المركز الأول بمجرد الكود. يحتاج الموقع إلى محتوى أصلي، صور حقيقية، سرعة، Search Console، Google Business Profile، روابط موثوقة وتحديث مستمر.
