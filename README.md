# مذاق مكناس — V3 Dashboard

المشروع يحتوي على متجر ثنائي اللغة + لوحة تحكم تجريبية.

## لوحة التحكم
افتح:
`/admin/`

رمز الدخول التجريبي:
`1234`

### حالياً تستطيع
- إضافة / تعديل / حذف المنتجات
- السعر والمخزون والصورة والوصف
- إدارة الطلبات وحالاتها
- ملخص الزبناء
- إعدادات SEO بالدارجة والفرنسية
- بيانات WhatsApp وInstagram
- LocalStorage

## مهم جداً للإنتاج
هذه لوحة تحكم Front-end تجريبية. لا تستخدم PIN `1234` ولا LocalStorage لحماية بيانات حقيقية.

النسخة الإنتاجية التالية يجب أن تستعمل:
- Firebase Authentication
- Firestore
- Storage
- Security Rules
- Firebase App Check عند الحاجة
- إنشاء الطلبات في Firestore
- صلاحيات Admin حقيقية
- منع العميل من تعديل السعر/المخزون
- Webhooks/notification حسب نظام الدفع والشحن
